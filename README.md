Votre emploi du temps, vos notes, vos travaux à faire et vos messages à porté de main, c'est
possible possible avec ANTINOTE !

notre intégration profonde au système d'exploitation nous sommes capables de vous proposer des
fonctionnalités poussées :
- [x] Mise à jour des données en arrière-plan
- [x] Calendrier dans l'application du téléphone
- [x] Comptes chiffrés et sécurisés biométrie
